## ADDED Requirements

### Requirement: Доступ до и после окончания срока пароля

Система SHALL отсчитывать срок пароля от момента последней смены как 90 периодов по 24 часа. После успешной проверки второго фактора признак `password_change_required` и доступ по выданной сессии должны соответствовать возрасту пароля. При достижении срока требуется смена.

#### Scenario: До истечения срока пароля осталась минута

- **GIVEN** до окончания 90 суток с последней смены пароля осталась минута
- **WHEN** сотрудник вводит правильный пароль и подтверждает код из письма
- **THEN** ответ второго фактора содержит `password_change_required: false`
- **AND** запрос по выданной сессии к `GET /api/patients` возвращает HTTP 200

#### Scenario: Срок пароля истёк минуту назад

- **GIVEN** с последней смены пароля прошло 90 суток и одна минута
- **WHEN** сотрудник вводит правильный пароль и подтверждает код из письма
- **THEN** ответ второго фактора содержит `password_change_required: true`
- **AND** запрос по выданной сессии к `GET /api/patients` возвращает HTTP 403 с причиной `password_expired`

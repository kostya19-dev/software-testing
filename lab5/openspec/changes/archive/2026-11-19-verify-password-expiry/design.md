## Context

Срок пароля хранится через дату его последней смены в MongoDB. Время читают два обработчика Go: подтверждение кода и проверка доступа к API.

## Goals / Non-Goals

Оба примера проходят через настоящий вход, почту Mailpit и защищённый маршрут клиники. Сценарий восстановления доступа после смены пароля уже покрыт отдельным тестом.

## Decisions

Перед входом фикстура задаёт дату последней смены относительно текущего времени. Запас в минуту позволяет выполнить HTTP-запросы по одну сторону границы без ожидания. Два сценария получают отдельные учётные записи. Тест читает булево поле ответа так, чтобы обнаружить и его отсутствие.

## Risks / Trade-offs

Эти E2E-примеры различают поведение за минуту до и через минуту после срока. Точное совпадение с моментом истечения на системных часах таким прогоном подтвердить нельзя.

# Тестирование программного обеспечения

Лабораторные работы на примере VitaLine Clinic.

## Ветки

- `lab1` — модульные тесты: домен, сервисы и хранилища; Allure, сценарии UC/TC и покрытие.
- `lab2` — интеграционные и e2e-тесты, постоянный Docker-стенд, параллельные сессии, Allure и CI.

## Лабораторная работа №1

```bash
cd lab1
make setup
make test
make check-docs
make show
```

Полная инструкция: [lab1/README.md](lab1/README.md).
Сценарии: [lab1/docs/spec.md](lab1/docs/spec.md).

Код приложения находится в `project/VitaLineClinic`: он нужен для локальной зависимости Go-модуля.
Сгенерированные отчёты, зависимости инструментов и локальные настройки не включены в Git.
